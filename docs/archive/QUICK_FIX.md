# Быстрое исправление проблемы с редиректом

## Что было сделано:
✅ Улучшена проверка заполненности анкеты (теперь проверяет реальную запись в БД)
✅ Исправлена логика редиректов (payment → questionnaire → onboarding)
✅ Код скомпилирован без ошибок

## Что нужно сделать СЕЙЧАС:

### Шаг 1: Исправить данные в базе
1. Откройте Supabase Dashboard
2. Перейдите в SQL Editor
3. Скопируйте и выполните скрипт из файла `CHECK_AND_FIX.sql`

Или выполните вручную:
```sql
-- Установить флаг для всех с заполненной анкетой
UPDATE profiles
SET questionnaire_completed = true
WHERE id IN (
  SELECT user_id 
  FROM client_questionnaires
);
```

### Шаг 2: Очистить кеш браузера
1. Откройте сайт
2. Нажмите `Ctrl + Shift + Delete`
3. Выберите "Cookies и другие данные сайтов"
4. Нажмите "Удалить данные"

### Шаг 3: Перезапустить сервер
```bash
# Остановите текущий (Ctrl+C)
npm run dev
```

### Шаг 4: Проверить
1. Откройте сайт
2. Войдите в аккаунт
3. Вас должно перенаправить на `/onboarding` (если анкета заполнена)

## Если все еще не работает:

### Вариант А: Проверить в базе данных
```sql
SELECT 
  p.email,
  p.questionnaire_completed,
  CASE WHEN q.id IS NOT NULL THEN 'ДА' ELSE 'НЕТ' END as анкета
FROM profiles p
LEFT JOIN client_questionnaires q ON q.user_id = p.id
WHERE p.email = 'ваш@email.com';
```

Если анкета есть, но флаг `false`:
```sql
UPDATE profiles
SET questionnaire_completed = true
WHERE email = 'ваш@email.com';
```

### Вариант Б: Удалить localStorage
1. F12 (DevTools)
2. Application → Local Storage
3. Удалить все ключи с `sb-`
4. Перезагрузить страницу (F5)

### Вариант В: Попробовать в режиме инкогнито
1. Откройте браузер в режиме инкогнито
2. Зайдите на сайт
3. Войдите в аккаунт
4. Проверьте, работает ли редирект

## Логика работы (для понимания):

```
Вход → Проверка оплаты → Проверка анкеты → Редирект

1. Нет оплаты → /payment
2. Есть оплата, нет анкеты → /questionnaire
3. Есть оплата, есть анкета → /onboarding
4. Когорта началась → /dashboard
```

## Важно:
- Функция `isQuestionnaireCompleted()` теперь проверяет **реальную запись** в таблице `client_questionnaires`
- Она автоматически обновляет флаг `questionnaire_completed` в профиле
- Это более надежно, чем полагаться только на флаг
