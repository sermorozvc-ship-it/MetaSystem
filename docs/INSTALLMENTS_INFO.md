## Подключённые провайдеры

- **Яндекс Сплит:** 2/4/6/12/24 мес (сроки контролирует сам Яндекс)
- **Долями** (оплата частями от Т-Банка): 3/6/12 мес (сроки контролирует сам Долями)

**Отключены:** СБЕР (15–20%), ОТП Банк (16–21%) — слишком дорогие комиссии.

---

## Как это работает

Рассрочки работают **глобально** — показываются на всех тарифах (1/3/6 месяцев). Параметры `available_payment_methods` и `installments_disabled` **не работают** через API Продамуса (только GET-ссылки с `do=pay`). Управление методами оплаты — только через запросы в поддержку Продамуса (глобально для всего аккаунта).

Клиент выбирает срок рассрочки самостоятельно на форме Продамуса. Яндекс и Долями сами определяют, какие сроки показать (Продамус не может их ограничить).

## Почему оставили рассрочки

**Плюсы:**
- Повышают конверсию — клиенты покупают дорогие тарифы (59 900 ₽), которые без рассрочки не потянули бы
- Короткие сроки (2–6 мес) — комиссия 8,5–12% (терпимо)
- Долями — фиксированная комиссия 12% на всех сроках (удобно считать)

**Минусы:**
- Яндекс 12/24 мес — комиссия 17,5% (дорого), но отключить нельзя (Яндекс контролирует сам)
- Рассрочки показываются на всех тарифах (1/3/6 мес) — нельзя ограничить программно

**Решение:**  
Оставили рассрочки (Яндекс + Долями), отключили СБЕР и ОТП (15–21%). Риск дорогих сроков 12/24 мес есть, но без рассрочки теряем продажи — лучше 49 000 ₽ с комиссией, чем 0 ₽ без продажи.

## Управление рассрочками

- **Подключить/отключить провайдеров** (Яндекс, Долями, СБЕР, ОТП) — через запрос в поддержку Продамуса
- **Ограничить сроки** у Яндекса/Долями — **нельзя** (они сами определяют, какие сроки показать клиенту)
- **Сделать рассрочку только на тариф 6 мес** — **нельзя** (параметры API не работают, только глобально для всех платежей)

Контакт поддержки: через ЛК Продамуса или по email/чату на сайте payform.ru.
