# E2E Test Scenarios — MetaSystem v2

## Цель
Проверить полный пользовательский флоу от регистрации до работы с программами.

---

## Сценарий 1: Регистрация и оплата нового клиента

### Шаги:
1. **Регистрация**
   - [ ] Открыть `/auth`
   - [ ] Зарегистрироваться с новым email
   - [ ] Проверить редирект на `/payment`

2. **Выбор тарифа**
   - [ ] Выбрать тариф "3 месяца"
   - [ ] Добавить галочку "План питания +3000₽"
   - [ ] Проверить корректный расчет итоговой суммы (35900 + 3000 = 38900₽)
   - [ ] Нажать "Оплатить"

3. **Оплата (тестовая)**
   - [ ] Открывается форма ЮMoney
   - [ ] Вернуться на страницу ожидания
   - [ ] Проверить статус "Ожидание подтверждения"
   - [ ] Вручную подтвердить оплату через админ-панель или вебхук

4. **Анкета**
   - [ ] После подтверждения оплаты редирект на `/questionnaire`
   - [ ] Заполнить Шаг 1: возраст, пол, рост, вес
   - [ ] Заполнить Шаг 2: цель, опыт, дни тренировок, оборудование
   - [ ] Заполнить Шаг 3: травмы, сон, стресс, активность
   - [ ] Заполнить Шаг 4: замеры, загрузить фото (опционально)
   - [ ] Нажать "Завершить"
   - [ ] Проверить редирект на `/dashboard`

### Ожидаемый результат:
- ✅ Клиент зарегистрирован
- ✅ Оплата подтверждена
- ✅ Анкета заполнена
- ✅ Подписка активна
- ✅ Клиент на дашборде

---

## Сценарий 2: Админ загружает программу клиенту

### Шаги:
1. **Вход как админ**
   - [ ] Войти с админским аккаунтом
   - [ ] Открыть `/admin`
   - [ ] Проверить статистику (количество клиентов, активных, оплат)

2. **Открыть карточку клиента**
   - [ ] Перейти в `/admin/clients`
   - [ ] Выбрать клиента из списка
   - [ ] Открыть вкладку "Программы"

3. **Загрузить программу**
   - [ ] Нажать "Загрузить программу"
   - [ ] Вставить Markdown программы (или нажать "Загрузить пример")
   - [ ] Указать номер недели: 1
   - [ ] Указать даты: текущая неделя
   - [ ] Указать количество дней: 3
   - [ ] Проверить предпросмотр
   - [ ] Нажать "Сохранить"

4. **Проверка**
   - [ ] Программа появилась в списке
   - [ ] Статус: "Активная"

### Ожидаемый результат:
- ✅ Программа загружена
- ✅ Клиент видит программу в `/programs`

---

## Сценарий 3: Клиент заполняет тренировку

### Шаги:
1. **Открыть программу**
   - [ ] Войти как клиент
   - [ ] Открыть `/programs`
   - [ ] Проверить наличие программы "Неделя 1"
   - [ ] Нажать "Открыть"

2. **Заполнить День 1**
   - [ ] Открыть День 1
   - [ ] Для каждого упражнения заполнить:
     - Вес (кг)
     - Повторения
     - RPE (1-10)
     - Комментарий (опционально)
   - [ ] Проверить автосохранение (сообщение "✓ Сохранено")
   - [ ] Заполнить самочувствие:
     - Энергия (1-10)
     - Настроение (1-5)
     - Качество сна (1-5)
     - Заметки
   - [ ] Нажать "Завершить тренировку"
   - [ ] Проверить статус "Завершено"

3. **Проверка прогресса**
   - [ ] Вернуться на `/programs`
   - [ ] Проверить прогресс-бар (33% для 3-дневной программы)

### Ожидаемый результат:
- ✅ Тренировка заполнена
- ✅ Данные сохранены
- ✅ Прогресс обновлен

## Сценарий 4: Клиент добавляет метрики

### Шаги:
1. **Открыть метрики**
   - [ ] Открыть `/metrics`
   - [ ] Нажать "Добавить замер"

2. **Заполнить замер**
   - [ ] Указать дату
   - [ ] Заполнить:
     - Вес (кг)
     - % жира (опционально)
     - Талия, бедра, грудь (см)
     - Сон (часов)
     - Стресс (1-10)
     - Вода (литров)
   - [ ] Добавить заметки
   - [ ] Нажать "Сохранить"

3. **Проверка графиков**
   - [ ] Проверить график "Динамика веса"
   - [ ] Проверить график "Объемы"
   - [ ] Проверить график "Образ жизни"

### Ожидаемый результат:
- ✅ Замер добавлен
- ✅ Графики обновлены
- ✅ Данные отображаются корректно

## Сценарий 5: Админ просматривает прогресс клиента

### Шаги:
1. **Открыть карточку клиента**
   - [ ] Войти как админ
   - [ ] Открыть `/admin/clients/[userId]`

2. **Проверить вкладки**
   - [ ] Вкладка "Анкета":
     - Проверить все заполненные данные
     - Проверить стартовые фото
   - [ ] Вкладка "Программы":
     - Проверить список программ
     - Открыть программу
     - Проверить заполненные данные клиента (read-only)
   - [ ] Вкладка "Метрики":
     - Проверить графики клиента
     - Проверить таблицу изменений

### Ожидаемый результат:
- ✅ Админ видит все данные клиента
- ✅ Realtime-обновления работают
- ✅ Данные корректны

## Сценарий 6: Чат между клиентом и тренером

### Шаги:
1. **Клиент отправляет сообщение**
   - [ ] Открыть `/messages`
   - [ ] Написать сообщение тренеру
   - [ ] Нажать "Отправить"

2. **Тренер отвечает**
   - [ ] Войти как админ
   - [ ] Открыть `/messages`
   - [ ] Выбрать чат с клиентом
   - [ ] Написать ответ
   - [ ] Нажать "Отправить"

3. **Проверка Realtime**
   - [ ] Клиент видит ответ мгновенно (без перезагрузки)
   - [ ] Тренер видит сообщение клиента мгновенно

### Ожидаемый результат:
- ✅ Сообщения отправляются
- ✅ Realtime работает
- ✅ История сохраняется

## Сценарий 7: Истечение подписки

### Шаги:
1. **Вручную изменить дату окончания**
   - [ ] В БД установить `subscription_end_date` на вчерашнюю дату
   - [ ] Установить `subscription_status = 'expired'`

2. **Проверка доступа**
   - [ ] Войти как клиент
   - [ ] Проверить дашборд (должно быть уведомление)
   - [ ] Попытаться открыть программу (должен быть редирект на `/payment`)

### Ожидаемый результат:
- ✅ Клиент видит уведомление об истечении подписки
- ✅ Доступ к программам ограничен
- ✅ Редирект на страницу оплаты

## Сценарий 8: Мобильная адаптация

### Шаги:
1. **Открыть на мобильном устройстве**

   - [ ] Проверить все страницы:
     - `/auth` — форма авторизации

   - [ ] Модальные окна открываются снизу
   - [ ] Input не вызывает зум при фокусе

### Ожидаемый результат:
- ✅ Все страницы адаптированы
- ✅ UI удобен на мобильных
- ✅ Нет багов с версткой
