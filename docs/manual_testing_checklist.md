# Manual Testing Checklist — MetaSystem v2

## Быстрая проверка перед деплоем

### 1. Авторизация ✅
- [ ] Регистрация нового пользователя работает
- [ ] Вход существующего пользователя работает
- [ ] Выход из системы работает
- [ ] Редирект неавторизованных на `/auth`

### 2. Страница оплаты ✅
- [ ] Отображаются 3 тарифа
- [ ] Чекбокс питания работает (для 1 и 3 мес)
- [ ] Бейдж "В подарок" на 6-мес тарифе
- [ ] Итоговая сумма рассчитывается корректно
- [ ] Кнопка "Оплатить" открывает ЮMoney
- [ ] Статус "Ожидание" отображается
- [ ] Polling работает (автообновление статуса)

### 3. Анкета ✅
- [ ] Прогресс-бар работает
- [ ] Все 4 шага заполняются
- [ ] Валидация обязательных полей
- [ ] Загрузка фото работает
- [ ] Кнопка "Завершить" сохраняет данные
- [ ] Редирект на `/dashboard` после завершения

### 4. Дашборд ✅
- [ ] Отображается имя пользователя
- [ ] Статистика подписки корректна
- [ ] Текущая программа отображается (если есть)
- [ ] Быстрые действия работают
- [ ] Последний замер отображается (если есть)

### 5. Программы ✅
- [ ] Список программ отображается
- [ ] Текущая программа выделена
- [ ] Прогресс-бары работают
- [ ] Клик на программу открывает детали
- [ ] Статусы программ корректны (Активная, Завершено, Ожидает)

### 6. Детальная программа ✅
- [ ] Навигация по дням работает
- [ ] Упражнения отображаются
- [ ] Видео-ссылки кликабельные
- [ ] Поля ввода работают
- [ ] Автосохранение работает (сообщение "✓ Сохранено")
- [ ] Слайдеры самочувствия работают
- [ ] Кнопка "Завершить тренировку" работает
- [ ] Статус "Завершено" отображается

### 7. Метрики ✅
- [ ] Кнопка "Добавить замер" открывает модалку
- [ ] Форма замера заполняется
- [ ] Замер сохраняется
- [ ] Графики отображаются:
  - Динамика веса
  - Объемы
  - Образ жизни
- [ ] Фото-галерея работает (если есть фото)

### 8. Чат ✅
- [ ] Список сообщений отображается
- [ ] Отправка сообщения работает
- [ ] Realtime-обновления работают
- [ ] Сообщения сортируются по времени

### 9. Админ-панель ✅
- [ ] Статистика отображается
- [ ] Список клиентов отображается
- [ ] Клик на клиента открывает карточку
- [ ] Вкладки работают:
  - Анкета
  - Программы
  - Метрики
- [ ] Загрузка программы работает
- [ ] Предпросмотр MD работает
- [ ] Кнопка "Загрузить пример" работает

### 10. Мобильная версия ✅
- [ ] Все страницы адаптированы
- [ ] Кнопки достаточно большие
- [ ] Нет горизонтального скролла
- [ ] Модальные окна открываются корректно
- [ ] Input не вызывает зум

## Критические баги (блокеры деплоя)

### 🔴 Высокий приоритет:
- [ ] Оплата не работает
- [ ] Данные не сохраняются
- [ ] RLS-политики пропускают чужие данные
- [ ] Вебхук не подтверждает оплату
- [ ] Realtime не работает

### 🟡 Средний приоритет:
- [ ] Графики не отображаются
- [ ] Автосохранение не работает
- [ ] Фото не загружаются
- [ ] Анимации лагают

### 🟢 Низкий приоритет:
- [ ] Мелкие баги UI
- [ ] Опечатки в тексте
- [ ] Неоптимальная производительность
