# Тестовый режим оплаты

## Что добавлено:

✅ Кнопка "Пропустить оплату (тест)" на странице `/payment`
✅ Автоматическое создание подтвержденного платежа
✅ Работает только в режиме разработки (NODE_ENV === 'development')

## Как использовать:

### 1. Запустите dev сервер:
```bash
npm run dev
```

### 2. Зарегистрируйтесь:
- Откройте http://localhost:3001
- Нажмите "Регистрация"
- Заполните email и пароль
- Войдите в систему

### 3. На странице оплаты:
Вы увидите две кнопки:
- **"Оплатить X ₽"** - реальная оплата через ЮMoney
- **"Пропустить оплату (тест)"** - тестовая оплата (только в dev режиме)

### 4. Нажмите "Пропустить оплату (тест)":
- Автоматически создастся подтвержденный платеж
- Вас перенаправит на `/questionnaire`
- Заполните анкету
- После заполнения вас перенаправит на `/onboarding`

## Что происходит при тестовой оплате:

1. Создается запись в таблице `payments` со статусом `confirmed`
2. Устанавливается:
   - `payment_method: 'manual'`
   - `confirmed_by: 'test'`
   - `confirmed_at: текущая дата`
   - `cohort_start: следующий понедельник`
3. Выбранный тариф и опции сохраняются
4. Пользователь перенаправляется на следующий шаг

## Важно:

⚠️ **Кнопка тестовой оплаты НЕ будет видна в продакшене!**

Она отображается только когда:
```javascript
process.env.NODE_ENV === 'development'
```

## Проверка созданного платежа:

Запустите скрипт проверки:
```bash
node scripts/check-users.js
```

Вы увидите:
```
📧 Email: ваш@email.com
   💳 Оплата: confirmed (35900 ₽)
   📋 Анкета: ❌ Не заполнена (или ✅ Заполнена)
```

## Удаление тестовых данных:

Если нужно начать заново:
```bash
node scripts/clean-all-data.js
```

Это удалит всех пользователей и все платежи.

## Логика работы:

```
Регистрация → Оплата (тест) → Анкета → Onboarding → Dashboard
     ↓            ↓              ↓          ↓           ↓
   /auth      /payment      /questionnaire /onboarding /dashboard
              [Тест кнопка]
```

## Для продакшена:

В продакшене кнопка тестовой оплаты автоматически скрыта.
Пользователи будут видеть только реальную оплату через ЮMoney.

## Функции в коде:

### `createTestPayment()` в `src/lib/services/payment.ts`
Создает подтвержденный платеж с выбранным тарифом.

### `handleTestPayment()` в `src/app/payment/page.tsx`
Обрабатывает нажатие на кнопку тестовой оплаты.

## Тестирование полного флоу:

1. ✅ Регистрация нового пользователя
2. ✅ Тестовая оплата (пропуск реальной оплаты)
3. ✅ Заполнение анкеты
4. ✅ Переход на onboarding
5. ✅ Ожидание начала когорты
6. ✅ Переход на dashboard (когда когорта началась)

Теперь можно тестировать весь флоу без реальной оплаты! 🚀
